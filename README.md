# API Examples

Kokoelma erilaisia API-esimerkkejä ja CRUD-toteutuksia eri teknologioilla ja tietokantaratkaisuilla.

Projektin tarkoituksena on toimia käytännön **minimi** esimerkki- ja harjoitteluprojektina API-rajapintojen, tietokantojen sekä backend-teknologioiden toteutuksesta.

Alkuperäinen toteutus **2023**. Ei päivitetty sen jälkeen.

**EI TEKOÄLYÄ KÄYTETTY tuolloin**.

📌 Projektin tila: Esimerkkiprojekti / harjoitteluprojekti

---

## Projektin sisältö

Repository sisältää useita itsenäisiä API-esimerkkejä, jotka on koottu samaan projektiin.

### GraphQL API

**GraphQL-API-CRUD_MySQL**

GraphQL-pohjainen CRUD API, jossa tietokantana käytetään MySQL:ää.

* GraphQL
* CRUD
* MySQL

### REST API – MySQL

**REST-API_CRUD_MySQL**

REST API -toteutus CRUD-toiminnoilla käyttäen MySQL-tietokantaa.

* REST API
* CRUD
* MySQL

### REST API – ASP.NET / C#

**REST-API_ASP.NET_c-**

REST API -esimerkki ASP.NET- ja C#-teknologioilla.

* ASP.NET
* C#
* REST API
* CRUD

### REST API – MongoDB

**REST-API_CRUD_MongoDB**

REST API -toteutus MongoDB-tietokannalla.

* REST API
* CRUD
* MongoDB

### REST API – PostgreSQL

**REST-API_CRUD_PostgreSQL**

REST API -toteutus PostgreSQL-tietokannalla.

* REST API
* CRUD
* PostgreSQL
